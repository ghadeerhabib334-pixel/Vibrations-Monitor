ℹ️  Expected Behaviors (Not Bugs):

1. Command Timeout Warning:
   - When dashboard disconnects during pending command
   - Error is logged but server continues running
   - This is normal and handled gracefully

2. Dashboard Not Connected:
   - MCP commands will fail if dashboard not open
   - Error message: "Dashboard not connected"
   - Solution: Open index.html in browser

3. MQTT Connection:
   - Requires MQTT broker configuration in dashboard
   - Dashboard connects to MQTT separately
   - MCP server only monitors, doesn't connect to MQTT
